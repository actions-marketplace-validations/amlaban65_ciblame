# Contributing to ciblame

Thanks for helping! ciblame is a small, dependency-free Go codebase; most contributions take minutes to review.

## Development

```sh
git clone https://github.com/amlaban65/ciblame && cd ciblame
go test -race ./...
go run ./cmd/ciblame --demo        # sample report, no token needed
go run ./cmd/ciblame your-org/your-repo
```

Requirements: Go 1.23+. There are no third-party dependencies, and we'd like to keep it that way, so please open an issue before adding one.

Layout:

| Path | What lives there |
|---|---|
| `internal/gh` | GitHub REST client: pagination, 1,000-result window splitting, rate limits, retries |
| `internal/classify` | Attribution rules and `signatures.json` |
| `internal/pricing` | Runner detection from labels, per-minute rates, billable-minute rounding |
| `internal/collect` | Fetches runs, jobs and PRs; links runs to PRs; produces one priced, attributed record per run |
| `internal/report` | Aggregation, insights, and the table / Markdown / JSON / CSV renderers |
| `internal/demo` | Deterministic sample data behind `--demo` |
| `internal/cli` | Flags and commands |

Before sending a PR: `gofmt -l .` prints nothing, `go vet ./...` is clean, and `go test -race ./...` passes.

## Adding or fixing an agent signature

Agents and bots are recognised by entries in [`internal/classify/signatures.json`](internal/classify/signatures.json):

```json
{
  "id": "my-agent",
  "name": "My Agent",
  "kind": "agent",
  "vendor": "Example Inc.",
  "logins": ["my-agent[bot]"],
  "branch_prefixes": ["my-agent/"],
  "emails": ["agent@example.com"],
  "trailers": ["^co-authored-by:\\s*my agent\\s*<"],
  "body_patterns": ["generated by my agent"],
  "workflow_paths": ["dynamic/agents/my-agent"],
  "workflow_path_suffixes": []
}
```

- `kind` is `agent` (does work autonomously) or `bot` (automation such as dependency updates).
- Every list is optional; prefer **stable, specific** signals. An account login or a no-reply e-mail address beats a name in a trailer (a person can be called "Claude").
- `trailers` and `body_patterns` are Go regular expressions, matched case-insensitively.
- `workflow_paths` match substrings of a run's workflow path. A match means the run *is* the agent executing, so it's reported as agent runtime.

Please include:

1. **Evidence** in the PR description: a link to a public PR, commit or run showing the signal, or the vendor's docs.
2. **A test case** in [`internal/classify/classify_test.go`](internal/classify/classify_test.go) using that evidence.

`ciblame why <run-url> --signatures my.json` lets you check a signature against a real run before opening the PR.

## Reporting a wrong attribution

Open an issue with the output of `ciblame why <run-url>` and what you expected. If the repository is private, redact names; the evidence line is what matters.

## Commit messages

Short imperative subject (`classify: recognise Jules branches`), a body explaining *why* when it isn't obvious. One logical change per PR.
